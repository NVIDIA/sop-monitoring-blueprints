# Helper Scripts

This directory contains utility scripts for working with the SOP Monitoring Inference Blueprint.

**Note:** `sop_scriptlib` is a Python package containing common functions used by several scripts. To make it discoverable by the Python interpreter, execute scripts from this directory (i.e., when `pwd` is this directory).

## Debugging & Development Scripts

These scripts are useful for debugging and reproducing the behavior of inference-bp components outside of the full deployment.

### temporal_segmentation.py

A CLI tool to trigger temporal segmentation using the `action_segment/ddm_net` algorithm.

**Execution Environment:**
This script must be executed inside the `sop_inference_bp:action_segment_x.x.x` Docker image.

**Note:** You will need to mount model weights and video data into the container.

**Example Docker Command:**
```bash
docker run -it --rm \
  --gpus all \
  --ipc=host \
  --ulimit memlock=-1 \
  --ulimit stack=67108864 \
  --entrypoint /bin/bash \
  -v $PWD/..:/workspace/sop-inference-bp \
  sop_inference_bp:action_segment_1.0.0
```

**Required Input:**
The script requires an annotation JSON file, which can be generated using `collect_annotations.py`.

**Usage:**
```bash
# Inside the container, navigate to the scripts directory
cd /workspace/sop-inference-bp/scripts
# Check the help output for available options
python temporal_segmentation.py -h
```

### collect_annotations.py

A utility script to generate annotation JSON files required by `temporal_segmentation.py`.

### action_recognition.py

A CLI tool to perform action recognition using a Vision Language Model (VLM). This script can reuse the output JSON (e.g., `f1_0.xx.json`) generated by `temporal_segmentation.py` to chunk videos and run VLM inference on each chunk.

**Execution Environment:**
This script must be executed inside the `sop_inference_bp:vlm_inference_service_x.y.z` Docker image.

**Note:** You will need to mount the VLM model weights, video data, and temporal segmentation output into the container.

**Example Docker Command:**
```bash
docker run -it --rm \
  --gpus all \
  --ipc=host \
  --ulimit memlock=-1 \
  --ulimit stack=67108864 \
  --entrypoint /bin/bash \
  -v $PWD/..:/workspace/sop-inference-bp \
  sop_inference_bp:vlm_inference_service_1.0.0
```

**Usage:**
```bash
# Inside the container, navigate to the scripts directory
cd /workspace/sop-inference-bp/scripts

# Run action recognition with temporal segmentation output
python action_recognition.py \
  --video /path/to/video.mp4 \
  --vlm_model_dir /path/to/vlm_model \
  --prompt_path /path/to/prompt.txt \
  --temporal_seg_json outputs_temporal_segmentation/f1_0.xx.json \
  --output_dir outputs_action_recognition

# Or run on entire video without segmentation
python action_recognition.py \
  --video /path/to/video.mp4 \
  --vlm_model_dir /path/to/vlm_model \
  --prompt_path /path/to/prompt.txt \
  --output_dir outputs_action_recognition

# Check help for all options
python action_recognition.py -h
```

**Debugging Workflow:**
Using `temporal_segmentation.py` and `action_recognition.py` together allows you to reproduce and debug what happens in the inference-bp components:
1. First, run `temporal_segmentation.py` to get event detection metrics, boundaries, and visualization.
2. Then, run `action_recognition.py` with the segmentation output to perform VLM inference on those chunks.
3. This two-step process mirrors the pipeline in the full deployment.

## Blueprint Testing Utilities

The following scripts are designed to test and verify a running blueprint instance launched via `docker compose up`.

### upload_files.py

A utility script to test file upload functionality of the deployed blueprint. It also generates a JSON file which can be used by `verify_bp.py` later.

**Dependencies:**
- `openai`
- `requests`

**Execution Environment:**
Can be run anywhere with the required dependencies and a recent Python version installed.

**Installation:**
```bash
pip install openai requests
```

### verify_bp.py

A utility script to verify the blueprint deployment and test its functionality. Can optionally use the JSON file generated by `upload_files.py` for testing.

**Dependencies:**
- `openai`
- `requests`

**Execution Environment:**
Can be run anywhere with the required dependencies and a recent Python version installed.

**Installation:**
```bash
pip install openai requests
```

## Notes

- **Debugging & Development Scripts**:
  - `temporal_segmentation.py` must be run inside the `sop_inference_bp:action_segment_x.x.x` Docker container
  - `action_recognition.py` must be run inside the `sop_inference_bp:vlm_inference_service_x.y.z` Docker container
  - Both require appropriate volume mounts for model weights and video data
  - Use these together to reproduce the full inference pipeline for debugging
- **Blueprint Testing Utilities**: Assume the blueprint services are running and accessible (typically started with `docker compose up`).
- **Python Path**: When running scripts that depend on `sop_scriptlib`, ensure you execute them from the `scripts/` directory.
